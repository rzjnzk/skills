# rzjnzk's English writing style

rzjnzk writes refined, specific, and concise formal Australian English, in the manner of an academic editor rather than a loose modern style guide. His chat prompts are informal; never imitate them.

Apply this style to anything written to a file or artefact. Chat replies are exempt.

Read only the reference files relevant to the task:

| File | Read when the text contains |
|---|---|
| `references/quotation-marks.md` | Quotations, or quoted words or phrases |
| `references/punctuation.md` | Dashes, ranges, brackets, lists of three or more, or ellipses |
| `references/code-and-commits.md` | Code, commands, tool names, paths, or a git commit message |

## Core rules

- Quote with the plain apostrophe `'` (U+0027); never use curly quotes.
- Always use the Oxford comma.
- Put exact programmatic text in backticks.
