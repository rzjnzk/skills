# Quotation marks

- The primary quotation mark is the plain keyboard apostrophe `'` (U+0027).
- Use the plain keyboard double quotation mark `"` (U+0022) only for a quotation within a quotation.
- Never use curly quotation marks: U+2018 `‘`, U+2019 `’`, U+201C `“`, or U+201D `”`.
- This is the British and formal Australian order. Do not use the American order of double quotation marks first and single quotation marks within them.

Example: `He said, 'The sign read "closed" when I arrived'.`
